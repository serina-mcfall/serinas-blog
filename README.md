# Serina's Blog

A personal blog built on Vite + React + TypeScript.

The design is driven by a North Star document. Before changing anything, read:

- **[North Star](docs/declaration/north-star.md)** — testable outcome declarations and the "what we won't accept" list.
- **[v1 Design Spec](docs/superpowers/specs/2026-05-12-serinas-blog-design.md)** — the implementation that satisfies the North Star.

A design that serves a declaration is justified. A design that doesn't needs a reason.
